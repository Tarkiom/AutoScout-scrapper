Clé GitHub

Pour lancer une recherche depuis ce site, il lui faut une clé qui a le droit de démarrer le workflow de ton repo. Elle reste enregistrée sur cet appareil uniquement.

  1. Ouvre github.com → nouveau token.
  2. Nom : autoscout-radar, expiration au choix.
  3. Repository access → Only select repositories → ton repo.
  4. Permissions → Repository → Actions : Read and write. Rien d'autre.
  5. Generate token, copie-le et colle-le ici.
