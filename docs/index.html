Clé GitHub

Pour lancer une recherche depuis ce site, il lui faut une clé qui a le droit de démarrer le workflow de ton repo. Elle reste enregistrée sur cet appareil uniquement.

  1. Ouvre github.com → nouveau token.
  2. Nom : autoscout-radar, expiration au choix.
  3. Repository access → Only select repositories → ton repo.
  4. Permissions → Repository → Actions : Read and write. Rien d'autre.
  5. Generate token, copie-le et colle-le ici.

Réglages

Sert à afficher la distance de chaque annonce (à vol d'oiseau, comme le rayon d'AutoScout24) et à trier par proximité. Sans code postal, la distance est calculée depuis celui de la recherche. Il reste sur cet appareil.

Alertes sur le téléphone

  1. Installe l'app gratuite ntfy (App Store ou Play Store).
  2. Abonne-toi à un nom de canal difficile à deviner, par exemple radar-xxxx.
  3. Dans ton repo : Settings → Secrets → Actions → New repository secret, nom NTFY_TOPIC, valeur = ce nom de canal.
  4. Coche « Surveiller toutes les 6 h » sur tes recherches : tu reçois une notification pour chaque nouvelle bonne affaire et chaque baisse de prix.

Pour Discord, même principe avec un secret DISCORD_WEBHOOK contenant l'URL du webhook de ton salon.
